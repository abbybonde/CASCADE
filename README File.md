Method(s) – Raw data is collected from a specialized instrument, BCARS, and pre-processed into it’s raw data form of a standard 3D .h5 file. Processing takes place using a publicly-available software CRIkit2. Post-processing of the data implements a cellular segmentation using CellposeSAM and then Raman peak-fitting pipeline known as CASCADE. It is up to this point where the segmented and fitted data has been stored and provided. Peaks were identified and analyzed through a python notebook that can be found in the CASCADE github repository; named BCARSFitting.ipynb. 
Location where data were collected – Data collected in the Krone Engineered Biosystems Building on the campus of the Georgia Institute of Technology. 
Time period during which data were collected -  Data was collected September 2025
